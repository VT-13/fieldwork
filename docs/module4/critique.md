# Module 4 UI verification

Discovery and sourced intelligence extend the existing paper/forest/serif/ruled design, generated contracts and resource client. Search/import, candidate acceptance, sources, actual durable job state, stop/retry, evidence currentness and generation history are inspectable. Unavailable paid work is disabled with an explanation; it does not pretend to have executed.

17 fictional browser tests passed, with the four existing flagship views at desktop/laptop/tablet/phone plus new discovery/prospect scans. Tests cover keyboard/URL state, responsive overflow, axe accessibility, failure/empty/unavailable/stopped work and explicit unsent regeneration. Rendered discovery phone/laptop and prospect phone/laptop captures were inspected: no clipped controls or new visual framework. Mobile uses the established vertical form/list flow and retains native labels/targets.

These are Chrome fixture/browser checks, not Safari, live providers or production usability measurements. Evidence shown in fixtures is deliberately fictional/unknown where unsupported; screenshots do not certify actual company facts. See verification.json and browser-results.json.
